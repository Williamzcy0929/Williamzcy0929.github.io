**September 2024 – May 2025**

I compared overlapping group LASSO implementations and implemented an optimized algorithm in C for integration with R.

## My Contributions

- Compared overlapping_LeastR from the MATLAB SLEP library with oglasso in the R package VennLasso under matched problem sizes and convergence tolerances.
- Simulated 1,000 large sparse-matrix datasets with overlapping groups and compared runtime using t-tests.
- Implemented the optimized algorithm in C for integration with R.

**Supervision:** Prof. Tianxi Li, University of Minnesota.
